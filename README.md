# gemini-cli-usage

`gemini-cli-usage` shows your Gemini CLI model quotas from the terminal, for Gemini Code Assist Standard and Enterprise accounts.

```sh
uv tool install gemini-cli-usage
gemini-cli-usage
```

`gemini-cli-usage` is developed in [clanker-usage](https://github.com/wakamex/clanker-usage), which also has the documentation, the issue tracker, and matching monitors for Claude Code, Codex, Antigravity, Cursor, Devin, DeepSeek, OpenCode Go and Z.ai. This repository holds its history up to version 0.1.9 and is read-only.

Every version stays on PyPI. 0.4.0 changed the options, JSON output and cache location ([release notes](https://github.com/wakamex/clanker-usage/releases/tag/v0.4.0)); to keep the earlier behavior, install `gemini-cli-usage==0.1.9`.
